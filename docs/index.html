Git-native drift detector

Keep agent edits attached to the repo truth.

Coherence checks when code, docs, ADRs, tests, metrics, generated files, endpoints, and evidence stop agreeing. It gives coding agents JSON they can act on.

Start in 30 seconds Read algorithm reference

Quickstart

Install the release binary, initialize rules for an agent repo, then run the worktree review before handoff or commit.

Step 1

Install

curl -fsSL https://github.com/fireharp/coherence/releases/latest/download/install.sh | sh

Step 2

Initialize

coherence init --template=agent-repo

Step 3

Review

coherence review --base=HEAD --worktree --json

What a useful failure looks like

Tests can pass while the repository gets less coherent. Coherence reports that as a typed regression with a concrete next action.

{
  "safe_to_commit": true,
  "review_recommended": true,
  "drift_verdict": "telemetry",
  "drift_regression_count": 1,
  "drift_regressions": [
    {
      "kind": "newly_orphaned_endpoint",
      "id": "endpoint:GET:/api/orders",
      "suggested_action": "add or restore a test that verifies the source file defining endpoint:GET:/api/orders"
    }
  ],
  "recommended_next_command": "coherence drift --json"
}

The commit is not blocked, but the agent has work.

The endpoint lost its verification path. A coding agent can inspect `drift_regressions`, restore a test or evidence link, then rerun `coherence review`.

Use cases

Use Coherence where normal tests do not explain whether the repository still tells one story.

Scenario Command What you get
Coding agents coherence review --base=HEAD --worktree --json Worktree drift, typed regressions, suggested commands, and a machine-readable commit verdict.
Pre-commit coherence scan --staged Fast staged-file checks against ontology rules before drift reaches history.
PR review coherence review --base=origin/main --staged --json PR-shaped signal across the branch diff plus staged local changes.
Zero-drift CI coherence review --base=origin/main --worktree --json --strict Telemetry promoted to exit 1 when CI needs every drift signal handled.
Debugging coherence drift --json Full meter output for broken links, orphan endpoints, stale tests, trace coverage, and optional Go callsite meters.

Agent workflow

Agents should consume the JSON contract, not parse human prose.

1

Review

coherence review --base=HEAD --worktree --json

2

Inspect

drift_regressions[]
suggested_commands[]

3

Repair

Restore the missing test, evidence, generated artifact, link, or ontology-paired file.

4

Rerun

coherence review --base=HEAD --worktree --json
